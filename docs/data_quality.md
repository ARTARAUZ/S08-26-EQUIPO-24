# Calidad de Datos

Este documento define los estándares de calidad de datos para el proyecto.

**IMPORTANTE:** Aún no se ha seleccionado dataset. Este es el marco de trabajo.

---

## Dimensiones de calidad

### Nulos
- Identificar columnas con valores faltantes.
- Decidir: imputar, eliminar o dejar como indicador.

### Duplicados
- Detectar registros duplicados.
- Eliminar o consolidar según corresponda.

### Outliers
- Identificar valores atípicos.
- Validar si son errores de medición o fenómeno real.

### Consistencia
- Unidades correctas.
- Rango de valores válidos.
- Formato de timestamps.
- machine_id consistente.

### Completitud
- Cobertura de sensores por máquina.
- Gaps temporales.
